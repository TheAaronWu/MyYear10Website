My Game

This game is inspired by SCP Containment Breach, a game made on April 15, 2012. Like the original version of the game, there are iconic SCPs such as 173, 106, and 939. However, due to time constraints, the game was unable to be fully recreated. But with the time I had, I was able to recreate the light containment area and also lore-accurate versions of the SCPs mentioned previously. Most models and animations from the game are taken from the original game or the canceled Unity remake.
